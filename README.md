## サービス概要
ライフゲージは、生年月日をもとに人生の「現在地（今何%生きたか）」を算出するWebアプリです。  
残り時間をゲージ（メーター）で直感的に表示します。  
「いつかやりたい」を「今やる」に変えるきっかけを提供します。

---

## このサービスへの思い・作りたい理由
『DIE WITH ZERO』を読んだことをきっかけに、
「やりたいと思っていたことを、結局やらずに終えてしまう」
という体験を自分自身が何度もしてきたことに気づきました。

若いうちにしかできないことがあるにもかかわらず、
人は「まだ時間がある」と思い込み、行動を先延ばしにしてしまいがちです。

このサービスは、行動を管理・強制するのではなく、
人生の有限性を可視化することで、
ユーザー自身が自然と「今やろう」と思える状態を作ることを目的としています。

---

## ユーザー層について
- **20〜40代の社会人**

仕事や家庭で忙しく、やりたいことを後回しにしがちな層を想定しています。  
時間の価値を理解し始めている一方で、
行動に移す明確なきっかけを得にくいと考えたためです。

---

## サービスの利用イメージ
1. ユーザー登録を行い、生年月日を登録する  
2. 人生の進捗率（ライフゲージ）が表示され、自分の人生の現在地を確認できる  
3. 人生でやりたいこと（Want）を登録する  
4. AIが「今日5分でできる行動」を提案し、行動のきっかけを作る  
5. Wantを達成したら記録する  
6. やりたいことや達成したことを他のユーザーと共有することができる  
7. 共感した投稿には"いいね"、"コメント"をすることができる

## サービスの差別化ポイント・推しポイント
- 人生の進捗率を「ゲージ」で直感的に可視化するUI  
- 行動を強制するのではなく、人生の有限性に気づきを与える設計  
- AIが「今日5分でできる行動」を提案し、小さな行動のきっかけを作る  
- やりたいことや達成した経験を共有し、他のユーザーと共感し合える仕組み 

### 類似サービス

**Bucket List**

人生でやりたいことをリスト化し、達成状況を管理するサービスです。  
目標や経験を整理し、人生でやりたいことを可視化できます。

**LifeLeft / みん寿**

生年月日などをもとに、人生の残り時間や進捗率を数値やグラフで可視化するサービスです。


ライフゲージでは、"人生の進捗率（時間）"と"やりたいこと（経験）"を組み合わせることで、  
限られた人生の時間の中で「何を経験するか」を考えるきっかけを提供します。

## 機能

### MVPリリース時の機能
- ユーザー登録 / ログイン
- 生年月日登録
- 人生進捗率（ライフゲージ）の表示  
  - 進捗率
  - 残り日数
  - ゲージ表示
- やりたいことリスト（Want）のCRUD
- タスク期限の設定
- 達成記録（達成日の記録）
- DIE WITH ZERO思想紹介ページ

### 本リリースの機能

#### 投稿・共有機能
- やりたいこと / 達成内容の共有（公開・非公開選択）
- いいね / コメント機能
- 写真付き投稿
- 一覧画面での写真表示

#### 目標管理機能
- タイムバケット（5年単位）での目標管理
- 目標寿命の変更

#### 通知機能（LINE通知）
- 通知頻度の設定（毎日 / 毎週）
- 優先度の高いやりたいことの通知
- AIによる「今日5分でできる行動」提案
